# Editorial notes

These documents hold everything that was taken out of the published texts on 20 September 2026, when the
biographies, the works summaries and the event cards were put into their public form. A published reference
block now holds references only. What stood beside each reference before – the Zotero or corpus key of the
source, how its page numbers were established, what was quoted at second hand, what no text in the library
supports, which dates or editions disagree, and what was checked against which web reference work – is kept
here, entry by entry, under the person and the file it came from.
